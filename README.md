# wecom. מאגר ידע פנימי

פלטפורמת ידע לנציגי שירות ותמיכה של wecom.

כתובת: https://inbarliat4-stack.github.io/KnowledgeBase/

## איך הפלטפורמה פועלת

התוכן מאורגן לפי **עולמות תוכן → נושאים → פריטי ידע**. כל פריט משתמש במבנה המתאים למטרתו:

- **M** – אבחון והכוונה למסלול טיפול
- **R / S** – הוראות טיפול ומסלולים מקצועיים
- **O** – הוראות לביצוע פעולה במערכת או בתהליך
- **E** – הנחיות להסלמה והעברה
- **T** – תסריטי שיחה
- **I** – מידע והסברים

**נציגים** מחפשים וקוראים פריטים שפורסמו ומשתמשים במסלולי האבחון. **עורכים** יוצרים, מעדכנים, מוחקים ומאשרים פריטים. מסך הכניסה מאפשר לבחור תפקיד כדי לראות כל תצוגה; זו הדגמה בלבד ואינה מגבילה גישה.

### טיוטות ואישור

לכל פריט יש סטטוס: טיוטה, ממתין לאישור, פורסם, לא בתוקף או ארכיון. נציגים רואים רק פריטים שפורסמו. עדכון לפריט קיים נשמר כ**גרסה מוצעת** לצד התוכן הנוכחי, והעורך יכול להשוות, לערוך, לאשר או לדחות אותה.

מונה ספריית הידע מציג את מספר הפריטים לפי הסינון שנבחר. המסנן **הנצפות ביותר** מציג עד עשרה פריטים שנפתחו לאחרונה בדפדפן הנוכחי.

### שמירה

התוכן נשמר בדפדפן (`localStorage`), כולל סל המחזור והיסטוריית הגרסאות. שינויים שנעשו בדפדפן אחד אינם מופיעים בדפדפן אחר.

## מבנה הפרויקט

```
KnowledgeBase/
├── index.html      ← האפליקציה כולה: עיצוב, קוד ותוכן מובנה
├── docs/           ← דפי המקור המקוריים, מקושרים מהפריטים
├── shared.css      ← עיצוב דפי docs/
├── scripts/        ← סקריפטים להכנת טיוטות ממסמכי מקור
└── drafts/         ← טיוטות Word שהסקריפטים יוצרים
```

כשמשנים את התוכן המובנה ב-`index.html`, יש להעלות את `NB_SEED_VERSION` באחד. בכניסה הבאה הפריטים המובנים מתעדכנים, ונושאים שמשתמשים יצרו נשמרים.

## הכנת טיוטות ממסמכי מקור

הסקריפטים קוראים קובצי DOCX מתיקייה מקומית. קובצי המקור אינם משתנים.

```powershell
# הצגת הגרסאות המוצעות לפריטים בעלי קוד תואם (ללא שמירה)
node scripts/import-source-revisions.cjs "מסמכי DOCx מוכנים לפרסום"
# הוספתן ל-index.html
node scripts/import-source-revisions.cjs "מסמכי DOCx מוכנים לפרסום" --write

# טיוטות Word לפריטים חדשים, תחת drafts/new-app-items/
node scripts/build-new-source-item-docs.cjs "מסמכי DOCx מוכנים לפרסום"
node scripts/build-new-source-item-docs.cjs "מסמכי DOCx מוכנים לפרסום" --only=O-36

# טיוטות מובנות למסמכי SharePoint, תחת drafts/sharepoint-structured/
node scripts/build-sharepoint-structured-docs.cjs <תיקיית הייבוא> <תבנית O-50.docx>
```

`import-source-revisions.cjs` מוסיף גרסאות מוצעות לפריטים קיימים בעלי קוד תואם, וקודים חדשים מתווספים כטיוטות ממתינות לאישור. מסמכי Word שנוצרים כוללים את הצעת המבנה ואת מסמך המקור המלא לצורך השוואה.
